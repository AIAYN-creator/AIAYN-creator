# AGENTS.md

This repository is the GitHub profile README of AIAYN-creator. Read this before changing anything.

## How it is built

- `README.md` is hand-written Markdown and HTML. Every image in it is an SVG in `assets/`, in a light and a dark version, chosen with `<picture>` and `prefers-color-scheme`.
- **Never edit an SVG by hand.** They are all generated by `tools/build_svgs.py` from the lists at the top of that file (`ELEMENTS`, `FINDINGS`, `FAMILIES`) and from `assets/data.json` (commit counts and daily contributions).
- After any change to `tools/build_svgs.py`, run it and commit the regenerated SVGs in the same commit:

  ```bash
  python tools/build_svgs.py            # offline, from assets/data.json
  python tools/build_svgs.py --refresh  # fetch fresh numbers with the gh CLI first
  ```

- The numbers refresh themselves: `.github/workflows/refresh.yml` runs `--refresh` every day and on every push to `main`, and commits the result. Don't add a manual step for that.

## Adding or changing a project

1. Add or edit its row in `ELEMENTS` (symbol, name, repo, family, tag). The symbol must be unique.
2. If it has a headline result, add a card to `FINDINGS`. The number and the claim must come from that repository's own README or results; never round up or invent one.
3. Add the matching `<a><picture>…</picture></a>` block to `README.md` in its family's row.
4. Run the build and check the README in both light and dark mode before committing.

## Rules

- Nothing that says where the author lives: no addresses, stops, streets or places more specific than a field of study. The profile itself names no one; the handle is AIAYN-creator.
- English only in this repository.
- The tone is a scientific paper: Abstract, Results, Findings, Methods. Keep it.
